# ARTESANOS — Plantilla V1.1

Primera propuesta visual HTML/CSS/JS para validar la dirección del futuro theme WordPress.

## Abrir
Abre `index.html` directamente en el navegador.

Para una vista más realista puedes servir la carpeta:

```bash
cd artesanos-template-v1
python3 -m http.server 8080
```

Y visitar:

`http://localhost:8080`

## Incluye
- Header sticky y menú responsive
- Hero editorial
- Categorías
- Carrusel de productos destacado
- Tienda en grid de 8 productos
- Hero compacto para mostrar su contenido completo al entrar
- Bloque de proceso/oficio
- Bloque editorial de marca
- Valores
- Banner final
- Footer
- Reveal animations con IntersectionObserver
- Parallax muy sutil en Hero
- Carrusel con autoplay y easing
- `prefers-reduced-motion`

## Notas
- Los links todavía son placeholders.
- Los productos son ejemplos visuales basados en la arquitectura de categorías suministrada.
- No se incluyeron precios ficticios.
- Las fotografías utilizadas son las proporcionadas para esta prueba.
